# Site 3D Angels

Site estatico em HTML, CSS e JavaScript. Os arquivos de producao ficam na raiz do repositorio, incluindo `index.html`, `.htaccess`, `img/` e `favicons/`.

## Deploy

- Branch principal: `main`.
- Nao exige instalacao de dependencias nem etapa de build.
- Publique os arquivos do site na raiz publica da hospedagem, preservando as pastas e o arquivo `.htaccess`.
- As regras do `.htaccess` exigem uma hospedagem compativel com Apache.
- A conexao com a hospedagem e o deploy automatico ainda precisam ser configurados.

Arquivos ZIP de distribuicao, credenciais e o checkout antigo nao sao versionados. Nunca adicione senhas ou chaves ao repositorio.
